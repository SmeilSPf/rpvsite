# Известные люди V — Инструкция по управлению сайтом

Персональная база знаний / Википедия в тёмной теме с поддержкой умной ротации цитат в шапке, фоновой музыки, переключения динамического/статичного фона, системы статусов жизни и сортировки/фильтрации.

---

## 📁 Структура проекта

```text
famous-people-wiki/
│
├── index.html        # Главная страница сайта
├── style.css         # Оформление (тёмная тема, цитаты, фильтры, запрет копирования, статусы)
├── app.js            # Логика (ротация цитат, сортировка, localStorage, статичный фон, музыка, навигация)
├── data.js           # 🌟 ФАЙЛ С ПЕРСОНАЖАМИ И ЦИТАТАМИ (добавление людей, биографий, статусов и цитат)
├── bg.js             # 🌟 ФАЙЛ ФОНОВ И МУЗЫКИ (картинки фона и аудио)
├── music.mp3         # Файл вашей фоновой музыки
├── bg/               # Папка для фоновых картинок (bg1.jpg, bg2.jpg и т.д.)
└── person/           # Папка для фотографий персонажей (grigoriy.png, mops.png, prokofiy.png...)
```

## 💬 Цитаты в верхней шторке (Умный рандом)

В шапке сайта между названием и кнопками отображаются цитаты:
- Цитаты плавно меняются каждые **5 секунд**.
- **Умный рандом**: каждый цикл формируется случайная последовательность, и ни одна цитата не может выпасть два или три раза подряд.
- Добавлять и редактировать цитаты можно в массиве `SITE_QUOTES` файла [`data.js`](famous-people-wiki/data.js):

```javascript
const SITE_QUOTES = [
  "«Я смог и вы сможете.» — Григорий",
  "«Я стал тем, кем даже не мечтал быть...» — Мопс Мопсович",
  "«Главное это деньги и люди. Шучу, не люди.» — Барон ДеШон",
  "«Быть умным не значит быть впереди всех.» — Прокофий",
  // Добавляйте свои цитаты в кавычках через запятую
];
```

## 🔍 Сортировка и фильтрация персонажей

На главной странице справа от заголовка размещена панель выбора сортировки:
1. **Стандартная** (выбрана по умолчанию) — порядок отображения ровно такой, как персонажи записаны в [`data.js`](famous-people-wiki/data.js).
2. **По алфавиту (А-Я)** — сортирует персонажей по их имени с правильным учетом кириллицы и латиницы.
3. **Только живые** — отображает карточки только живых персонажей (со статусом `alive`).
4. **Только мертвые** — отображает карточки только погибших персонажей (со статусом `dead`).

> **💾 Сохранение выбора**: выбранная пользователем сортировка автоматически сохраняется в браузере (`localStorage`). Даже при перезагрузке страницы (`F5`) или повторном открытии сайта останется выбранная пользователем сортировка.

## 🔴 Статусы персонажей (Жив / Мертв)

В файле [`data.js`](famous-people-wiki/data.js) для каждого персонажа есть поле `status`:

```javascript
{
  id: "grigory",
  name: "Григорий",
  role: "Филантроп",
  status: "alive", // Укажите "alive" (Жив) или "dead" (Мертв)
  photo: "person/grigoriy.png",
  bio: `...`
}
```

- **`status: "alive"`** (или `true`) — **Жив**:
  - На главной странице справа от имени отображается **зелёный светящийся кружок**.
  - На странице биографии внизу отображается плашка **«Жив»** с зелёным кружком.
- **`status: "dead"`** (или `false`) — **Мертв**:
  - На главной странице справа от имени отображается **красный кружок**.
  - На странице биографии внизу отображается плашка **«Мертв»** с красным кружком.

## 🖼️ Кнопка статичного фона

В шапке сайта слева от кнопки музыки добавлена кнопка **статичного фона**:
- При клике смена фона останавливается на той фотографии, которая отображается в данный момент.
- Если в момент клика картинка плавно проявлялась, анимация плавно завершается без искажений или полусерых фонов.
- При повторном клике таймер (7 секунд) возобновляет работу, и картинки снова начинают меняться по кругу.

## 📋 Копирование текста

- Выделение и копирование текста **заблокировано** по всему сайту для чистоты интерфейса.
- **Разрешено копировать только текст самой биографии** внутри карточки детального просмотра персонажа.
